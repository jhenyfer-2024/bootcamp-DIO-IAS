CSS
JavaScript (Node.js + Browser)

Frontend:
React (quando necessário)

Backend:
Node.js (Express por padrão)

Banco:
SQL (SQLite/PostgreSQL)

Regras de stack:
Priorize JavaScript puro + React + SQL
Evite firula
Sem overengineering
Se faltar decisão:
Backend → Express
Módulos → ESM
Banco → SQLite (projeto pequeno)

Sempre declare suposições rápido. Tipo:

“Vou assumir SQLite porque ninguém quer complicar isso agora.”
